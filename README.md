Zara is an advanced voice assistant project utilizing computer vision (CV), speech recognition, and SQLite3 for database management. It converts voice inputs to text and responds with speech. Designed for seamless interaction, Zara showcases cutting-edge AI capabilities. Perfect for developers interested in AI-driven solutions.
# Zara - Desktop Voice Assistant

Zara is a Python-based voice assistant capable of performing a wide range of tasks, including web searches, managing applications, and interacting with the system. It uses speech recognition and text-to-speech technology to provide an interactive user experience.

## Features

- **Speech Recognition and Text-to-Speech:** Powered by `speech_recognition` and `pyttsx3` libraries.
- **Voice Commands:**
  - Web searches (Google, YouTube, Wikipedia).
  - System operations (shutdown, restart, lock, hibernate).
  - Application controls (Notepad, Paint, Command Prompt, etc.).
  - Browser controls (open, close, incognito mode, navigation).
  - Media controls (volume adjustment, mute/unmute).
  - Utilities (current time, screenshot, calculations).
- **Database Integration:** SQLite database for storing user information and voice commands.
- **Graphical User Interface (GUI):** Built using `tkinter` for easy interaction.

## Installation

2. Navigate to the project directory:
   ```bash
   cd zara-voice-assistant
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt

## Usage

1. Run the application:
   python zara.py
2. Use the GUI to start Zara or interact with it via voice commands directly.
